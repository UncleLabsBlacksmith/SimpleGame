รู้จัก Flutter

Flutter คือชุดเครื่องมือสร้าง UI จากโค้ดชุดเดียว

Flutter เป็นโอเพนซอร์สจาก Google เขียนด้วยภาษา Dart และวาดหน้าจอเองทุกพิกเซล แอปจึงหน้าตาและพฤติกรรมใกล้เคียงกันในทุกแพลตฟอร์ม

Multi-platform

โค้ดชุดเดียว

ส่วนใหญ่ใช้ร่วมกันได้ทุกแพลตฟอร์ม ส่วนที่ต่างกันจริง ๆ เช่นกล้องหรือการแจ้งเตือน ใช้ปลั๊กอินแทน

Native compile

ทำงานลื่น

ตอนปล่อยจริงคอมไพล์เป็นโค้ดเครื่องของมือถือและเดสก์ท็อป ส่วนเว็บคอมไพล์เป็น JavaScript หรือ WebAssembly

Hot reload

เห็นผลทันที

แก้โค้ดแล้วหน้าจอเปลี่ยนในไม่กี่วินาที โดยข้อมูลบนหน้าจอยังอยู่ ไม่ต้องกดย้อนกลับมาทดสอบใหม่

เริ่มต้น

ติดตั้งแล้วรันแอปแรกใน 4 ขั้นตอน

  1. 1ติดตั้ง Flutter SDK ตามคู่มือที่ docs.flutter.dev (มี Dart มาในตัว)
  2. 2ติดตั้งเอดิเตอร์ VS Code พร้อมส่วนเสริม Flutter หรือ Android Studio
  3. 3เตรียมเครื่องทดสอบ Android Emulator, Chrome หรือแอปเดสก์ท็อป ส่วน iOS ต้องใช้ Mac กับ Xcode
  4. 4ตรวจและรัน ด้วยคำสั่งทางขวา ถ้า flutter doctor ฟ้องอะไร ให้แก้ตามที่แนะนำ
# ตรวจว่าเครื่องพร้อมหรือยัง
flutter doctor

# สร้างโปรเจกต์ใหม่
flutter create hello_app
cd hello_app

# ดูเครื่องที่ใช้ได้ แล้วรัน
flutter devices
flutter run

โครงสร้างโปรเจกต์

ไฟล์ส่วนใหญ่ที่คุณแก้จะอยู่ใน lib/

hello_app/
├─ lib/
│  └─ main.dart
├─ test/
│  └─ widget_test.dart
├─ pubspec.yaml
├─ analysis_options.yaml
├─ android/
├─ ios/
├─ web/
└─ windows/  macos/  linux/
lib/main.dartจุดเริ่มต้นของแอป โค้ด Dart ทั้งหมดอยู่ในโฟลเดอร์ lib/
pubspec.yamlชื่อแอป เวอร์ชัน แพ็กเกจที่ใช้ รูปภาพ และฟอนต์
test/เทสต์ รันด้วย flutter test
analysis_optionsกฎตรวจคุณภาพโค้ด ใช้กับ flutter analyze
android/ ios/ ...โปรเจกต์ของแต่ละแพลตฟอร์ม แก้เมื่อต้องตั้งค่าไอคอน สิทธิ์ หรือการเซ็นแอป

ภาษา Dart

Dart อ่านง่าย ถ้าเคยเขียน Java หรือ JS

// ตัวแปร: var เปลี่ยนได้, final กำหนดครั้งเดียว
var count = 0;
final name = 'Somchai';
const pi = 3.14;

// Null safety: ? แปลว่าเป็น null ได้
String? nickname;
print(nickname ?? 'ไม่มีชื่อเล่น');

// งานที่ต้องรอ เช่น เรียก API
Future<String> load() async {
  await Future.delayed(const Duration(seconds: 1));
  return 'เสร็จแล้ว';
}

final กับ const

final รู้ค่าตอนรันได้ ส่วน const ต้องรู้ค่าตั้งแต่ตอนคอมไพล์

Null safety

ตัวแปรเป็น null ไม่ได้ ถ้าไม่ได้ใส่ ? ข้อผิดพลาดจึงเจอตั้งแต่ตอนเขียน

async กับ await

รอผลลัพธ์ได้โดยที่หน้าจอไม่ค้าง ใช้บ่อยมากกับเครือข่ายและไฟล์

State

เมื่อข้อมูลเปลี่ยน ให้เรียก setState แล้วหน้าจอจะอัปเดต

class Counter extends StatefulWidget {
  const Counter({super.key});
  @override
  State<Counter> createState() => _CounterState();
}

class _CounterState extends State<Counter> {
  int count = 0;

  @override
  Widget build(BuildContext context) {
    return TextButton(
      onPressed: () => setState(() => count++),
      child: Text('กดแล้ว $count ครั้ง'),
    );
  }
}

เปลี่ยนหน้าและใช้แพ็กเกจ

แอปจริงต้องมีหลายหน้าและดึงข้อมูลจากภายนอก

// ไปหน้าถัดไป และกลับมา
Navigator.of(context).push(
  MaterialPageRoute(builder: (_) => const DetailPage()),
);
Navigator.of(context).pop();

// เพิ่มแพ็กเกจ: flutter pub add http
import 'dart:convert';
import 'package:http/http.dart' as http;

Future<dynamic> fetchUser() async {
  final res = await http.get(
    Uri.parse('https://api.example.com/user'),
  );
  return jsonDecode(res.body);
}
