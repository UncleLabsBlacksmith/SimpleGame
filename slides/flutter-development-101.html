รู้จัก Flutter

Flutter คือชุดเครื่องมือสร้าง UI จากโค้ดชุดเดียว

Flutter เป็นโอเพนซอร์สจาก Google เขียนด้วยภาษา Dart และวาดหน้าจอเองทุกพิกเซล แอปจึงหน้าตาและพฤติกรรมใกล้เคียงกันในทุกแพลตฟอร์ม

เริ่มต้น

ติดตั้งแล้วรันแอปแรกใน 4 ขั้นตอน

  1. 1ติดตั้ง Flutter SDK ตามคู่มือที่ docs.flutter.dev (มี Dart มาในตัว)
  2. 2ติดตั้งเอดิเตอร์ VS Code พร้อมส่วนเสริม Flutter หรือ Android Studio
  3. 3เตรียมเครื่องทดสอบ Android Emulator, Chrome หรือแอปเดสก์ท็อป ส่วน iOS ต้องใช้ Mac กับ Xcode
  4. 4ตรวจและรัน ด้วยคำสั่งทางขวา ถ้า flutter doctor ฟ้องอะไร ให้แก้ตามที่แนะนำ
# ตรวจว่าเครื่องพร้อมหรือยัง
flutter doctor

# สร้างโปรเจกต์ใหม่
flutter create hello_app
cd hello_app

# ดูเครื่องที่ใช้ได้ แล้วรัน
flutter devices
flutter run

android/ ios/ ...โปรเจกต์ของแต่ละแพลตฟอร์ม แก้เมื่อต้องตั้งค่าไอคอน สิทธิ์ หรือการเซ็นแอป

ภาษา Dart

Dart อ่านง่าย ถ้าเคยเขียน Java หรือ JS

// ตัวแปร: var เปลี่ยนได้, final กำหนดครั้งเดียว
var count = 0;
final name = 'Somchai';
const pi = 3.14;

// Null safety: ? แปลว่าเป็น null ได้
String? nickname;
print(nickname ?? 'ไม่มีชื่อเล่น');

// งานที่ต้องรอ เช่น เรียก API
Future<String> load() async {
  await Future.delayed(const Duration(seconds: 1));
  return 'เสร็จแล้ว';
}

final กับ const

final รู้ค่าตอนรันได้ ส่วน const ต้องรู้ค่าตั้งแต่ตอนคอมไพล์

Null safety

ตัวแปรเป็น null ไม่ได้ ถ้าไม่ได้ใส่ ? ข้อผิดพลาดจึงเจอตั้งแต่ตอนเขียน

async กับ await

รอผลลัพธ์ได้โดยที่หน้าจอไม่ค้าง ใช้บ่อยมากกับเครือข่ายและไฟล์

class Counter extends StatefulWidget {
  const Counter({super.key});
  @override
  State<Counter> createState() => _CounterState();
}

class _CounterState extends State<Counter> {
  int count = 0;

  @override
  Widget build(BuildContext context) {
    return TextButton(
      onPressed: () => setState(() => count++),
      child: Text('กดแล้ว $count ครั้ง'),
    );
  }
}

ภาคผนวก: Flutter SDK

วิธีที่แนะนำ: ติดตั้ง Flutter ผ่าน VS Code

  1. 1ติดตั้ง Git ตามระบบของคุณ (ดูทางขวา)
  2. 2ติดตั้ง VS Code จาก code.visualstudio.com
  3. 3ลงส่วนเสริม กด Ctrl+Shift+X ค้นหา Flutter แล้วกด Install ส่วนเสริม Dart จะมาด้วย
  4. 4เริ่มติดตั้ง กด Ctrl+Shift+P แล้วเลือก Flutter: New Project
  5. 5ดาวน์โหลด SDK กด Download SDK เลือกโฟลเดอร์ แล้วกด Clone Flutter
  6. 6ตั้งค่า PATH กด Add SDK to PATH แล้วปิดและเปิดเทอร์มินัลกับ VS Code ใหม่

ติดตั้ง Git

# Windows
ดาวน์โหลด Git for Windows จาก git-scm.com

# macOS
xcode-select --install

# Debian, Ubuntu
sudo apt-get update -y

ภาคผนวก: Flutter SDK

ทางเลือก: ติดตั้ง SDK เองโดยไม่ใช้ VS Code

  1. 1ดาวน์โหลด ไฟล์ stable จาก docs.flutter.dev/install/manual
  2. 2สร้างโฟลเดอร์ develop ในโฟลเดอร์ผู้ใช้ เส้นทางต้องไม่มีช่องว่างหรืออักขระพิเศษ
  3. 3แตกไฟล์ ลงโฟลเดอร์นั้น
  4. 4เพิ่ม PATH บน Windows เพิ่ม %USERPROFILE%\develop\flutter\bin ใน Environment Variables แล้วย้ายขึ้นบนสุด
# Windows (PowerShell) เปลี่ยน X.Y.Z เป็นเวอร์ชันที่โหลดมา
Expand-Archive `
  -Path "$HOME\Downloads\flutter_windows_X.Y.Z-stable.zip" `
  -DestinationPath "$HOME\develop"

# macOS
unzip ~/Downloads/flutter_macos_X.Y.Z-stable.zip -d ~/develop/

# Linux
tar -xf ~/Downloads/flutter_linux_X.Y.Z-stable.tar.xz -C ~/develop/

# macOS: เพิ่มใน ~/.zprofile, Linux (bash): เพิ่มใน ~/.bashrc
export PATH="$HOME/develop/flutter/bin:$PATH"

# เปิดเทอร์มินัลใหม่ แล้วตรวจ
flutter --version
dart --version

ภาคผนวก: Android

Android ต้องมี Android Studio และ SDK ครบชุด

  1. 1ติดตั้ง Android Studio เวอร์ชัน stable ล่าสุด
  2. 2เปิด SDK Manager จาก More Actions หรือ Tools > SDK Manager
  3. 3แท็บ SDK Platforms เลือกรายการแรกที่เป็น API Level 36 แล้วกด Apply
  4. 4แท็บ SDK Tools เลือกเครื่องมือทั้ง 6 รายการทางขวา แล้วกด Apply
  5. 5ยอมรับใบอนุญาต รัน flutter doctor --android-licenses
  6. 6สร้างเครื่องจำลอง ใน Device Manager กด + เลือกรุ่นและ system image แล้วกด Run

SDK Tools ที่ต้องเลือก

  • Android SDK Build-Tools
  • Android SDK Command-line Tools
  • Android Emulator
  • Android SDK Platform-Tools
  • CMake
  • NDK (Side by side)
ข้อควรระวัง: ลงแค่ปลั๊กอิน Flutter ใน Android Studio ยังไม่พอ ต้องมี Flutter SDK และตั้งค่า PATH ด้วย

ภาคผนวก: iOS และ macOS

iOS และ macOS ต้องใช้เครื่อง Mac กับ Xcode

  1. 1ติดตั้ง Xcode เวอร์ชันล่าสุด
  2. 2ตั้งค่าและยอมรับใบอนุญาต ด้วยคำสั่งทางขวา
  3. 3ติดตั้ง CocoaPods ตามคู่มือของ CocoaPods จำเป็นสำหรับปลั๊กอินที่มีโค้ด native
  4. 4เฉพาะ iOS: ดาวน์โหลด iOS platform และ simulator
  5. 5เครื่อง iPhone จริง: เปิด Developer Mode และเซ็นแอปด้วยบัญชี Apple (บัญชีฟรีใช้ทดสอบได้)
# เลือก Xcode และตั้งค่าครั้งแรก
sudo sh -c 'xcode-select -s \
  /Applications/Xcode.app/Contents/Developer \
  && xcodebuild -runFirstLaunch'

# ยอมรับใบอนุญาต
sudo xcodebuild -license

# เฉพาะ iOS
xcodebuild -downloadPlatform iOS
