# เกมรถแข่ง (Racing Game)

เกมรถแข่งมุมมองจากด้านบน เขียนด้วย Python + tkinter ทั้งหมดอยู่ในไฟล์เดียว ไม่ต้องติดตั้ง library เพิ่ม

พัฒนาโดย Uncle Engineer

## ความต้องการของระบบ

- Python 3.8 ขึ้นไป (มี tkinter มาให้แล้วในตัวติดตั้งมาตรฐานของ Windows และ macOS)
- บน Linux บางดิสโทรต้องติดตั้ง tkinter เพิ่ม เช่น `sudo apt install python3-tk`

## วิธีเริ่มเกม

```bash
python racing_game.py
```

## ขั้นตอนการเล่น

1. **เลือกรถ** – เปิดเกมแล้วจะเจอหน้าเลือกรถ กด `←` `→` หรือคลิกที่รูปรถ
2. **เริ่มแข่ง** – กด `Space` / `Enter` หรือคลิกที่ภาพตัวอย่างรถ แล้วรอนับถอยหลัง 3-2-1
3. **หลบรถ** – ขับหลบรถเก๋งและรถบรรทุกบนถนน 4 เลน ชนเมื่อไหร่จบเกม
4. **เก็บไอเท็ม** – เก็บเหรียญ ถังไนโตร และโล่ เพื่อเพิ่มคะแนนและตัวช่วย
5. **จบเกม** – กด `Space` เพื่อเล่นใหม่ด้วยรถคันเดิม หรือกด `C` เพื่อกลับไปเลือกรถ

## ปุ่มควบคุม

| ปุ่ม | การทำงาน |
|---|---|
| `←` `→` / `A` `D` | เลี้ยวซ้าย / ขวา |
| `↑` / `W` | เร่งความเร็ว |
| `↓` / `S` | เบรก |
| `Shift` / `Space` | ใช้ไนโตร (ระหว่างแข่ง) |
| `P` | หยุดชั่วคราว / เล่นต่อ |
| `H` / `F1` | เปิด/ปิดเมนูช่วยเหลือ ดูปุ่มควบคุมและไอเท็ม (ระหว่างแข่ง เกมจะหยุดให้) |
| `C` | เปลี่ยนรถ (หน้าจบเกม) |
| `Esc` | ออกจากเกม |

ถ้าสลับไปหน้าต่างอื่นระหว่างเล่น เกมจะหยุดชั่วคราวให้อัตโนมัติ

## รถให้เลือก

ค่าพลังแต่ละด้านมีผลกับการขับจริง (คะแนน 1–5)

| รถ | ความเร็วสูงสุด | อัตราเร่ง | การควบคุม | ไนโตร | จุดเด่น |
|---|:-:|:-:|:-:|:-:|---|
| สปอร์ต | 3 | 3 | 3 | 3 | สมดุลทุกด้าน เหมาะกับมือใหม่ |
| ฟอร์มูล่า | 5 | 4 | 2 | 2 | เร็วที่สุด แต่คุมยาก |
| มัสเซิล | 4 | 5 | 1 | 3 | อัตราเร่งแรง แต่ตัวใหญ่ เลี้ยวหนัก |
| มินิ | 2 | 3 | 5 | 2 | ตัวเล็ก คล่องตัว หลบง่าย |
| ตำรวจ | 3 | 3 | 4 | 5 | ไนโตรจัดเต็ม มีไฟไซเรน |

- **ความเร็วสูงสุด** – เพดานความเร็วของรถ
- **อัตราเร่ง** – เร่งถึงความเร็วสูงสุดได้ไวแค่ไหน
- **การควบคุม** – เลี้ยวไวและหยุดเลี้ยวได้ทันแค่ไหน (รถคุมยากจะมีแรงเฉื่อยมาก)
- **ไนโตร** – ได้ไนโตรจากการเก็บเหรียญและถังไนโตรมากแค่ไหน

## ไอเท็มบนถนน

| ไอเท็ม | ผล |
|---|---|
| เหรียญ `$` (สีทอง) | +50 คะแนน และเติมไนโตรเล็กน้อย |
| ถังไนโตร `N` (สีส้ม) | เติมหลอดไนโตร (หลอดซ้ายจอ) |
| โล่ `S` (สีฟ้า) | กันชนได้ 1 ครั้งภายในเวลาจำกัด (หลอดขวาจอ) รถที่ชนจะกระเด็น +30 คะแนน |

## การคิดคะแนน

| วิธี | คะแนน |
|---|---|
| ระยะทาง | +1 ทุกๆ 10 หน่วยที่วิ่ง (ยิ่งเร็วยิ่งได้ไว) |
| แซงรถพ้นจอ | +5 ต่อคัน |
| แซงแบบเฉียดฉิว | +25 |
| เก็บเหรียญ | +50 |
| ใช้โล่ชนรถกระเด็น | +30 |

ยิ่งวิ่งไกล ถนนจะยิ่งเร็วและรถจะยิ่งหนาแน่นขึ้น

## เคล็ดลับ

- เก็บไนโตรไว้ใช้ตอนต้องเร่งแซงออกจากช่องแคบ
- แซงเฉียดบ่อยๆ ได้คะแนนเร็วมาก แต่เสี่ยงชน
- รถบรรทุกยาวกว่ารถเก๋งเกือบเท่าตัว เผื่อระยะตอนเปลี่ยนเลน
- เกมจะเว้นช่องให้หนีได้อย่างน้อย 1 เลนเสมอตอนสร้างรถใหม่

# ROAD CHASER – ถนนนักซิ่ง

เกมที่สองในโปรเจกต์ เป็นเกมแข่งรถแนว **Road Fighter** (Konami, 1984) ที่สร้างขึ้นใหม่ด้วย tkinter ไฟล์เดียวเช่นกัน
มีระบบหลักครบแบบต้นฉบับ และเพิ่มฟีเจอร์ใหม่อีกหลายอย่าง

```bash
python road_chaser.py
```

## เป้าหมาย

ขับให้ถึงเส้นชัย (GOAL) ของแต่ละด่านก่อนน้ำมันหมด ดูความคืบหน้าได้จากแถบแผนที่ด้านซ้ายจอ

- ชน **ขอบถนน / เกาะกลาง / รถบรรทุก / หิน** = ระเบิด เสียเวลา (และน้ำมัน) ระหว่างรอเกิดใหม่
- **ระเบิดได้ทั้งหมด 5 ครั้งต่อเกม** (นับรวมทุกด่าน ดูได้ที่ช่อง CRASH ด้านขวาจอ) ครบ 5 ครั้งเมื่อไหร่ = **Game Over**
  ส่วนการเฉี่ยวรถเก๋งจนรถหมุนไม่นับ
- ชน **รถเก๋ง** = รถหมุนไถล ต้อง **หักพวงมาลัยสวนทาง** เพื่อตั้งหลักให้ทันก่อนชนขอบถนน
- ชน **รถสีรุ้ง** = เติมน้ำมัน +20 และได้ +1000 คะแนน
- ถึงเส้นชัยแล้ว น้ำมันที่เหลือจะถูกแปลงเป็นคะแนน (หน่วยละ 100)

## ปุ่มควบคุม

| ปุ่ม | การทำงาน |
|---|---|
| `←` `→` | เลี้ยว |
| `↑` / `Z` | เร่งด้วยเกียร์ต่ำ (สูงสุด 200 km/h ออกตัวไว) |
| `Shift` / `X` | เกียร์สูง (สูงสุด 400 km/h แต่ออกตัวช้า) |
| `↓` / `C` | เบรก |
| `P` | หยุดชั่วคราว |
| `M` | เปิด/ปิดเสียง |
| `Enter` / `Space` | เลือกเมนู / ไปต่อ |
| `Esc` | กลับหน้าแรก (กดที่หน้าแรกเพื่อออกจากเกม) |

**เทคนิคแบบต้นฉบับ:** กดเร่งเกียร์ต่ำออกตัวก่อน พอใกล้ 200 km/h ค่อยกดเกียร์สูงค้างไว้ด้วย จะทำความเร็วได้ถึง 400 km/h
ปุ่มตัวอักษรใช้ได้แม้คีย์บอร์ดเป็นภาษาไทย

## ด่าน (6 ด่าน)

| ด่าน | ชื่อ | จุดเด่น |
|:-:|---|---|
| 1 | ทุ่งหญ้า (Grassland) | ถนนกว้าง รถน้อย เหมาะฝึกมือ |
| 2 | สะพานข้ามน้ำ (Water Bridges) | สะพานข้ามแม่น้ำหลายช่วง ถนนเริ่มแยกเลน |
| 3 | ริมทะเล (Seashore) | ชายหาดและทะเลด้านซ้าย คู่แข่งเริ่มปรากฏ |
| 4 | เทือกเขา (Mountain) | ถนนแคบ โค้งเยอะ มีหินตกบนถนน |
| 5 | ป่าลึก (Forest) | คราบน้ำมันเยอะ ถนนคดเคี้ยว |
| 6 | ทางด่วนยามค่ำ (Night Highway) | กลางคืน รถหนาแน่นที่สุด |

ผ่านด่านไหนแล้ว ด่านถัดไปจะปลดล็อกให้เลือกเริ่มจากหน้าแรกได้

## รถและสิ่งกีดขวาง

| สิ่งที่เจอ | พฤติกรรม |
|---|---|
| รถเหลือง | วิ่งตรงเลนเดิม |
| รถน้ำเงิน | เปลี่ยนเลนมาขวางเมื่อเราเข้าใกล้ |
| รถม่วง | ส่ายซ้าย-ขวาตลอดเวลา |
| รถบรรทุก | ตัวยาว ชนแล้วระเบิดทันที |
| รถสีรุ้ง (F) | รถเติมน้ำมัน ชนเพื่อเติมน้ำมัน |
| คู่แข่ง (สีดำแถบทอง) | พุ่งมาจากด้านหลัง วิ่งเกาะและเบียดเรา แล้วจะเร่งหนีไปเอง |
| คราบน้ำมัน | ทำให้รถลื่นหมุน |
| หิน | ชนแล้วระเบิด |
| ดาว | อมตะชั่วคราว ชนรถคันไหนก็ระเบิด +300 |

เบียดรถคันอื่นจนไปชนขอบถนนได้ +300 คะแนน

## ฟีเจอร์ที่เพิ่มจากต้นฉบับ

- 6 ด่าน (ต้นฉบับ NES มี 4 ด่าน) และด่านกลางคืน
- รถคู่แข่ง หิน และดาวอมตะ
- ระดับความยาก 3 ระดับ (ง่าย / ปกติ / ยาก) มีผลต่ออัตราการใช้น้ำมัน ความหนาแน่น และความเร็วของรถ
- เลือกด่านที่ปลดล็อกแล้วเป็นจุดเริ่มต้นได้จากหน้าแรก
- เมื่อ Game Over กด Enter เพื่อเริ่มใหม่ที่ STAGE 1 (คะแนนและจำนวนครั้งที่ชนได้เริ่มใหม่) หรือ Esc กลับหน้าแรก
- ตารางคะแนนสูงสุด 5 อันดับ และเวลาที่ดีที่สุดของแต่ละด่าน
- เสียงประกอบ (เฉพาะ Windows สร้างไฟล์เสียงเองตอนเปิดเกม ไม่ต้องใช้ไฟล์ภายนอก)
- หน้าวิธีเล่นพร้อมภาพประกอบรถแต่ละชนิด
- หยุดเกมอัตโนมัติเมื่อสลับไปหน้าต่างอื่น

| วิธี | คะแนน |

| ชนรถสีรุ้ง | +1000 |
| เบียดรถจนระเบิด / ชนรถตอนมีดาว | +300 |
